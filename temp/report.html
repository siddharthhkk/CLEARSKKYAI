1. Project Origin & Objective

ClearSky-AI is a deep learning architecture designed to perform cloud removal on satellite imagery by fusing multi-modal remote sensing data. Optical sensors (such as Sentinel-2) are frequently obstructed by cloud cover. Synthetic Aperture Radar (SAR) sensors (such as Sentinel-1) penetrate atmospheric clouds, capturing structural ground details regardless of weather conditions.

The objective of this system is to leverage a dual-stream U-Net architecture coupled with Spatial-Channel Attention (SCA) and PatchGAN discriminators to reconstruct clear, high-resolution optical imagery using paired SAR radar features and corrupted optical input.

2. Initial Setup & Cloud Infrastructure

We began with a raw dataset footprint of approximately 91 GB (50 GB Sentinel-1 SAR imagery and 41 GB Sentinel-2 Optical imagery). Setting up the local development environment inside the Cloud studio required addressing critical storage and version control bottlenecks:

  • Cloud Storage & Compute (Lightning.ai): To manage the heavy lifting required for this project, we are leveraging Lightning.ai. Their cloud platform serves as the backbone of our infrastructure, allowing us to securely store the massive 91 GB raw dataset in the cloud, circumventing local hardware limits, and providing seamless access to scalable GPU compute resources required for the U-Net training pipeline.
  • Git History Bloat Resolution: Initial repository tracking mistakenly staged the heavy data directories, bloating the hidden .git repository to over 47 GB. This would have caused severe GitHub push failures.
  • Repository Reset Protocol: We executed a clean local repository re-initialization by configuring a strict .gitignore ruleset (excluding data/), purging the local .git tree, re-initializing fresh tracking, and force-pushing to preserve the existing GitHub URL while dropping 47 GB of dead weight.

4. Investigation of Output Artifacts: The "Green Tint" Phenomenon

Diagnosis Output Image Appearing as Uniform Green Texture

Upon executing the first end-to-end inference pass, the Streamlit dashboard generated the three panels cleanly, but the ClearSky Output exhibited a uniform green noise pattern instead of a reconstructed terrain image.

Why did this happen?
The control panel flagged: "⚠️ Weights not found. Running with initialized architecture." In PyTorch, an un-trained neural network initializes its weights using standard random Gaussian distribution. Pushing SAR and optical features through an untrained network causes random tensor multiplication. When normalized from [-1, 1] back to RGB display range [0, 1], these random values average out into a uniform mid-frequency greenish texture.
